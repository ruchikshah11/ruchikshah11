### 🚀 Welcome to My GitHub Profile!

Hey there! I'm a **SharePoint, .NET & Power Platform developer** who enjoys turning messy manual processes into clean, automated systems. Whether it's a Nintex workflow, a Power Automate flow, or a C# console tool, I like building things that quietly make someone's day easier.

## 🙋 About Me

I specialize in **SharePoint solutions**, **.NET/C# development**, and **workflow automation** with Power Automate and Nintex — with Python and PowerShell scripts filling in the gaps. I'm currently expanding into Django and React/TypeScript, and brushing up on Java and data structures in C. Always up for digging into a tricky automation problem or a complex SharePoint migration — explore my repos below and feel free to reach out!
